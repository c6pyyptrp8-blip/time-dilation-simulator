⏳ 시간 지연 시뮬레이터

일반상대성이론과 특수상대성이론에서 나타나는 시간 지연 현상을 비교하는 탐구 프로그램

① 행성의 조건

M⊕ : 지구 질량의 배수
R⊕ : 지구 반지름의 배수
행성의 반지름은 지구 반지름으로 고정한 단순화 모델입니다.

② 물체의 속도

0.01은 빛의 속도의 1%를 의미합니다.

③ 시간 지연 계산 결과

중력에 의한 시간 지연

- 마이크로초 / 하루

속도에 의한 시간 지연

- 마이크로초 / 하루

두 효과를 함께 고려한 시간 지연

- 마이크로초 / 하루

두 개별 시간 지연 효과가 같아지는 속도

- km/s

④ 거리와 시간 지연의 관계

현재 설정한 행성 질량과 속도를 유지하면서 거리에 따라 시간 지연이 어떻게 변하는지 나타냅니다.

● 파란색: 중력 시간 지연
● 주황색: 속도 시간 지연

⑤ 물리학적 계산 원리

중력 시간 지연 비율
√(1 - 2GM / rc²)
속도 시간 지연 비율
√(1 - v² / c²)
결합 시간 지연 비율
√(1 - 2GM / rc²) × √(1 - v² / c²)
두 개별 효과가 같아지는 속도
v = √(2GM / r)

G : 만유인력 상수
M : 행성의 질량
r : 행성 중심으로부터의 거리
c : 빛의 속도
v : 해당 위치에서 측정한 물체의 속도
